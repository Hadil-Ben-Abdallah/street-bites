# <h1 align="center">🌮 STREET BITES — International Street Food Festival</h1>

An interactive website for a fictional international street food festival, bringing together food discovery, vendor exploration, and live event scheduling in one experience. Built with React, TypeScript, and gp-grid, this project combines a modern festival-inspired interface with interactive data grids and practical features across three data-driven pages.

---

## 🚀 Live Preview

🔗 [View live project!](https://street-bites-olive.vercel.app/)

---

## ✨ Features

- 🌮 **Festival Experience:** A multi-page website built around an international street food festival concept
- 🏪 **Vendor Directory:** Explore 100 fictional food vendors, with search, filtering, and multiple data views
- 🍜 **Food Explorer:** Discover 160 fictional dishes with detailed information, categories, and interactive filters
- 📅 **Festival Schedule:** Browse 72 events across three festival days, with day selection and event status updates
- 📊 **Advanced Data Grids:** Interactive tables powered by gp-grid, featuring sorting, filtering, grouping, and pivoting
- ✏️ **Inline Editing:** Update records through interactive editing controls
- 🎨 **Custom Cell Renderers:** Rich data presentation with images, badges, ratings, prices, and status indicators
- ⚡ **Virtual Scrolling:** Efficiently navigate larger datasets
- 🧭 **Multiple Data Views:** Switch between directory, grouped, and pivot views where available
- 📱 **Responsive Interface:** A festival-inspired experience designed for different screen sizes

## 🗺️ Project Structure

The application includes four main pages:

| Page | Description |
|---|---|
| 🏠 Home | Festival introduction and featured content |
| 🏪 Vendors | Searchable directory of 100 food vendors |
| 🍜 Food Explorer | Interactive exploration of 160 dishes |
| 📅 Festival Schedule | Three-day schedule featuring 72 events |

The Vendors, Food Explorer, and Festival Schedule pages use gp-grid to handle their interactive data experiences.

---

## 📊 Exploring gp-grid

One of the main goals of this project was to put [gp-grid](https://gp-grid.io/) into practice in a real React application.

The implementation explores features such as:

- Sorting and filtering
- Custom cell renderers
- Inline editing
- Row selection
- Row grouping and aggregation
- Pivot tables
- Virtual scrolling
- Column resizing and reordering
- Dynamic data updates

STREET BITES provides a practical playground for exploring how these features fit into a multi-page application.

## 💡 Inspiration

Street food brings together different cultures, flavors, and stories.

I wanted to turn that idea into an interactive digital festival where visitors can discover dishes, explore vendors, and find events throughout the festival.

The project also gave me an opportunity to experiment with advanced data-grid functionality in a realistic frontend application.

## 🔧 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Hadil-Ben-Abdallah/street-bites
```

Navigate to the project directory:

```bash
cd street-bites
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore the application.
